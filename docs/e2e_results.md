| Параметр | Значение |
|----------|----------|

| Топология | 4 workers × 2 cores × 4 ГБ RAM |

### Сводная таблица

| Стратегия | Среднее, с | σ, с | CV, % | Ускорение (среднее) | Вывод |
|-----------|-----------|------|-------|---------------------|-------|
| **RF + RandomSearch** | **62.9** | **1.0** | **1.7** | **×1.469** | ✓ Стабильно |
| DNN + RandomSearch | 56.4 | 4.4 | 7.8 | ×1.770 | ⚠ Высокая вариативность |
| RF + Q-Learning | 57.8 | 2.5 | 4.3 | ×1.719 | ✓ Стабильно |

CV (Coefficient of Variation) = σ / среднее × 100%. Порог стабильности: CV < 5%.

### RF + RandomSearch — детали

| Метрика | Значение |
|---------|---------|
| min / max | 60.4 с / 65.1 с |
| Среднее ± σ | 62.9 ± 1.0 с |
| CV | **1.7%** |
| Ускорение min/max | ×1.420 / ×1.532 |

**Стабильные параметры (≥80% совпадений):**
- `executor_memory_mb` = 4096 MB — **100%** ✓
- `shuffle_compress` = false — **100%** ✓
- `rdd_compress` = true — 80% ✓

**Вывод:** RF+RS показывает наименьшую вариативность из трёх стратегий. Модель уверенно выбирает `executor_memory_mb=4096` и отключение `shuffle_compress`. Параметры ресурсов (`executor_cores`, `executor_instances`) варьируются — модель считает несколько конфигурационных зон равноценными.

### DNN + RandomSearch — детали

| Метрика | Значение |
|---------|---------|
| min / max | 49.5 с / 63.7 с |
| Среднее ± σ | 56.4 ± 4.4 с |
| CV | **7.8%** |
| Ускорение min/max | ×1.558 / ×2.004 |

**Стабильные параметры (≥80% совпадений):**
- `executor_memory_mb` = 4096 MB — 85% ✓
- `shuffle_compress` = false — 85% ✓
- `spill_compress` = true — 95% ✓

**Вывод:** DNN+RS предсказывает самые быстрые конфигурации в среднем (56.4 с), но CV=7.8% превышает порог стабильности. Нейросеть чувствительна к случайному пулу кандидатов: разные подмножества пространства дают оценки с разбросом до 14 с. Это следствие меньшей точности модели (MAE=13.05 с vs MAE=8.97 с у RF). DNN не имеет доверительного диапазона — единственная оценка может содержать ошибку без индикации.

### RF + Q-Learning — детали

| Метрика | Значение |
|---------|---------|
| min / max | 51.8 с / 61.9 с |
| Среднее ± σ | 57.8 ± 2.5 с |
| CV | **4.3%** |
| Ускорение min/max | ×1.602 / ×1.914 |

**Стабильные параметры (≥80% совпадений):**
- `executor_memory_mb` = 4096 MB — 80% ✓
- `shuffle_compress` = false — 80% ✓
- `spill_compress` = true — **100%** ✓
- `io_codec` = lz4 — 90% ✓

**Вывод:** RF+QL занимает промежуточное положение: CV=4.3% (ниже порога), среднее ускорение ×1.719 сравнимо с DNN. Q-learning внедряет предвычисленный оптимальный конфиг как якорь в пул кандидатов, что объясняет стабильность `spill_compress=true` на уровне 100% — это характеристика QL-таблицы, найденной агентом за 800 эпизодов. DNN-скоринг (без доверительного диапазона RF) даёт большую вариативность, чем RF+RS, но меньшую, чем чистый DNN+RS.

### Сравнение доверительных диапазонов

| Стратегия | Тип диапазона | Наличие |
|-----------|--------------|---------|
| RF + RandomSearch | p5–p95 деревьев RF | ✓ Есть (показывает разброс предсказаний леса) |
| DNN + RandomSearch | — | ✗ Недоступен (нейросеть — одна оценка) |
| RF + Q-Learning | — | ✗ Недоступен (DNN-скоринг — одна оценка) |

### Выводы

1. **RF+RS — наиболее надёжная стратегия** для production: CV=1.7%, наличие доверительного диапазона, интерпретируемость
2. **RF+QL — баланс** между направленным поиском (Q-learning) и приемлемой стабильностью (CV=4.3%)
3. **DNN+RS — наибольший потенциальный speedup** (×1.770 в среднем), но высокая вариативность (CV=7.8%) и отсутствие диапазона ограничивают применение
4. **Все три стратегии сходятся** на `executor_memory_mb=4096 MB` как доминирующем выборе при данной топологии — это соответствует теоретическому оптимуму (максимальная RAM узла = 4 GB)
